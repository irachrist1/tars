# Onboarding screens — Duolingo-style flow

One question per screen. Numbered choices. Progress indicator (`3/8` installer, `11/14` in-Claude).

## Installer screens (1–8) — `tars install`

| # | Question | Choices |
|---|---|---|
| 1/8 | What should I call you? | free text |
| 2/8 | What's your work? | Consulting · Accounting · Legal · Founder · Other |
| 3/8 | Work folder | Yes, found OneDrive · Somewhere else |
| 4/8 | Meetings & notes | M365 · Google · Granola · None yet |
| 5/8 | AI tools | Claude only · Claude + ChatGPT · ChatGPT (export) |
| 6/8 | Never without asking | Email · Files · Post · All |
| 7/8 | Surfaces | Everywhere · Cowork/web · Code only |
| 8/8 | Handoff | Launch Claude · Copy prompt · `tars publish` hint |

Writes `onboarding-seed.md`. Runs bootstrap on next `tars open`.

## In-Claude screens (9–14) — first SKILL session

| # | Phase | Action |
|---|---|---|
| 9/14 | Adopt seed / workspace | Silent read of seed + bootstrap |
| 10/14 | Environment | Surfaces + Obsidian (one question) |
| 11/14 | Work folder confirm | Single confirm or correction |
| 12/14 | Read-back | Uncannily specific summary from real files |
| 13/14 | Proof | Real meeting prep with ≥2 citations |
| 14/14 | Publish + streak | `tars publish` or Code-only; handoff prompt |

See `references/onboarding.md` for director's script detail.

## Progress copy

Use: `Screen 4/8 — Where do your meetings live?`

Never stack multiple questions on one screen.
